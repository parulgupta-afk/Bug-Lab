# Bug Lab — 2-minute demo

1. **Hook (0:00–0:20)**  
   Open *The Infinite Loop*. Step until low/high stop progressing. Show the synchronized code + array + variables.

2. **Investigate (0:20–0:55)**  
   Click the bad boundary line → *Something's wrong*. Show the engine verdict and hints.

3. **Fix + verify (0:55–1:25)**  
   Choose `high = mid - 1` → Apply & verify. Show before/after (failure gone, correct result).

4. **Break It (1:25–1:45)**  
   Open Break It → preset *unsorted / risky* → Apply. Show wrong result on correct code. Switch to *The assumptions* challenge if needed.

5. **Close (1:45–2:00)**  
   "Students don't only see the right algorithm — they trace failure, fix it, and prove the fix."
